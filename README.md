# 発見ツベ（YouTube発見ページ）

ふだん見ないジャンルのYouTube動画を、「人気順」または「ランダム」で一覧表示するスマホ向けページです。
タップするとYouTubeで再生されます。

- 画面：`docs/`（GitHub Pagesで公開）
- 裏側：`worker/`（Cloudflare Worker `youtube-discover-api`）
- 公開URL：https://training-recorder.github.io/youtube-discover/

## 使い方

1. スマホのブラウザで上のURLを開く
2. ジャンルのボタンを押す、またはことばを入れて「検索」
3. 期間・並び・対象を切り替える（選んだ状態は次回も残ります）
4. 動画をタップするとYouTubeが開く
5. ランダムのときは、いちばん下の「別の動画を出す」で引き直せます（YouTubeの回数は減りません）

ホーム画面に追加すると、アプリのように開けます。
- iPhone：Safariで開く →「共有」→「ホーム画面に追加」
- Android：Chromeで開く → メニュー →「ホーム画面に追加」

## 「おまかせ」ボタン

いちばん左の「おまかせ」は、6ジャンルを混ぜて、ジャンルが交互に並ぶように20件出します。
各ジャンルの保存済みの結果を使うので、ほかのジャンルを開いたあとなら検索回数はほとんど使いません。

## 件数が少ないとき

10件未満のときは、自動で期間を1段広げて（24時間→今週、今週→今月）後ろに足します。
そのときは一覧の上に「後半は『今週』の動画で補っています」と表示されます。

## ジャンルの検索語を変える方法

1. `worker/src/index.js` を開く
2. 先頭の `GENRES` の中の `ja:`（日本語）と `en:`（英語）の「 " " の中身」を書き換える
   ```js
   economy:  { ja: "経済ニュース", en: "economy news" },
   ```
3. ボタンの表示名を変えたいときは、`docs/app.js` 先頭の `GENRES` の `label:` を書き換える
4. 保存して、次のコマンドを実行する（`worker` フォルダの中で）
   ```
   npx.cmd wrangler deploy
   ```
5. 検索結果は1〜6時間保存されるため、反映に少し時間がかかることがあります

## 回数の上限について

- YouTubeの検索は1日100回までです。ショート動画を避けるため、新しい条件1つにつき「4〜20分」「20分以上」の2回検索します。
- 同じ条件の結果は保存して使い回し（24時間以内=1時間、今週=3時間、今月=6時間）、
  95回に達したら保存済みの結果だけを返します（新しい条件は1日およそ47個まで）。
- タイトルの和訳は、Cloudflareの無料枠（1日10,000ニューロン）の範囲で動きます。超えたら原題のみの表示になります。

## 安全面

- YouTubeのAPIキーは、Cloudflareの「シークレット」にだけ登録してあり、画面側のファイルやGitHubには入っていません。
- Workerは、このページのURLからの呼び出しだけを受け付けます。
- 同じ相手からの連続呼び出しは、1分に20回までに制限しています。
